# Roadmap

Tickets, their scope and blockers live in the [GitHub issues](https://github.com/RedDial256/loomworks/issues) (`TNN: …`), one milestone per phase. Order follows tracer bullets: one thin end-to-end slice first, then widen.

| Phase | Goal | Tickets |
|---|---|---|
| 0 | Monorepo, Expo compatibility spike, CI | T01 to T03 |
| 1 | Tracer bullet: manifest, `loom init`, `loom add`, `Box` and `Text`, integration test | T04 to T08 |
| 2 | Accessibility and primitives | T09 to T16 |
| 3 | Interactive components | T17 to T23 |
| 4 | Expo SDK 58, template app, `weaver`, demos, `Input` with date and time, `Background` | T24 to T32, T35 to T37 |
| 5 | Quality, visual proof, deploy and release, first alpha | T33, T34, T38 to T44 |

## Not ticketed yet

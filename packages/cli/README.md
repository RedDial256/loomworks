# @red_dial/loom

Copies Loomworks components into an Expo SDK 58 project as source you own: themed with Unistyles 3, open-ended props, light and dark themes.

```sh
npx @red_dial/loom init        # theme, Unistyles setup, `@/theme` alias, loom.json
npx @red_dial/loom add button  # an item and its dependencies
```

Unistyles needs a development build (no Expo Go). `--help` lists the flags.
